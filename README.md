# Giù dalla Torre Online
Versione digitale multiplayer (3–8 giocatori) del party game *Giù dalla Torre!* di Dario Mansetti. Stack: React+Vite, Cloudflare Workers + Durable Objects (SQLite), costo zero.

Stato: **Fase 1 — analisi** (vedi `docs/PROGRESS.md`). Materiali originali in `docs/source-materials/originals/`; documentazione in `docs/`.
